# Indoor Misplaced-Item Detection Robot

**Author:** Luis Romero Sevilla

## About the Project

This project is an indoor mobile robot that moves through a home or office, uses its camera and computer vision to spot everyday items that are out of place (keys, phones, wallets, remote controls), and reports where it found them. The goal is to save people the time and frustration of searching for lost belongings by turning the robot into a helper that always knows where things were last seen.
